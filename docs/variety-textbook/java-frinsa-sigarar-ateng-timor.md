# Java Frinsa Manis: учебная страница  
## Sigarar Utang, Timor, Ateng + natural funky — не три региона, а три сорта в одном лоте

---

## 1. Контекст лота (твоя пачка)

- **Микролot / станция:** **Frinsa Manis** (Indonesia, **Java**)
- **Остров Java** — **география** (**Indonesia**)
- **На этикetке variety:** **Sigarar Utang, Timor, Ateng** — **три cultivar**, **не** **три** **места**
- **Обработка:** **Natural**
- **Обжарщик:** **Caffenation** (Belgium), линейка **Seasonally / Funky Stuff**
- **Ноты:** dark berries cheesecake, wild sweet winey, **lactic kefir acidity**

**Вывод:** учишь **не** «сорт Java как страна», а **blend genetics + natural ferment + roaster intent**.

---

## 2. Три названия — что каждое значит

### Sigarar Utang (сорт)

- **Indonesian cultivar**, **rust-era** **selection**
- **Имя:** «**расписывается в долг**» — **быстрый** **урожай**
- **В чашке (solo):** **body**, **предсказуемость** **на** **полях**; **в** **blend** — **структура**

### Timor / Tim Tim (линия Hibrido de Timor)

- **Genes** **от** **Arabica×Robusta** **cross** (**Timor-Leste**)
- **Не** **Catimor**, но **родственник** **по** **rust** **resistance**
- **В чашке:** **низкая** **кислотность**, **горечь** **risk** **при** **перегреве**, **earth** **optional**

### Ateng (сорт, не Aceh!)

- **Indonesian name** **Catimor-related** **compact** **lines** (**Ateng 1, Ateng super**)
- **≠ Aceh** (**провинция** **Sumatra**)
- **В чашке:** **коммерческий** **backbone**, **herbal**, **body**

**См. также:** раздел **Timor vs Catimor** в [`variety-brewing-atlas.md`](../variety-brewing-atlas.md).

---

## 3. Почему natural + funky + lactic

**Natural** **=** **ferment** **в** **ягоде** **2+ недели**. **Specialty** **Java** (**Frinsa**) **часто** **контролируют** **лучше** **commodity** → **winey, berry, lactic** **без** **гнили** (**в** **идеале**).

**Lactic** **notes** **≠** **обязательно** **lactic** **process** **на** **станции** — **могут** **быть** **from** **microbial** **profile** **natural** **+** **sorting**.

**Заварка:** **не** **искать** **чайную** **прозрачность** **как** **Ethiopia washed**.

## 4. Обработка и заварка (матрица)

| Если бы было… | Метод | Почему |
|---------------|-------|--------|
| **Washed Java Typica** | V60 **92 °C** | **Чистота** |
| **Wet-hull Sumatra** | Immersion / espresso | **Earth, body** |
| **Natural Frinsa blend (ты)** | **AP + bypass** **88–90 °C** | **Ferment + blend size** **→** **иммерсия** **выравнивает** |
| **Alternative** | **Switch ≤1:30** | **Сладость** **без** **long** **hot** **V60** |

### Эталон AP (старт)

- **15 g / ~85–90 ml**, **1:00–1:20**, **88–90 °C**
- **Bypass** **до** **150–180 ml**
- **Grind 11–12** (твоя шкала, **как** **Indonesia Periskop** **5★**)

### Если пробуешь V60

- **91 °C** **max**, **ступени**, **не** **250 ml** **одним** **литьём**
- **Оцени** **lactic** **остроту** — **если** **колет** → **−2 °C** **или** **AP**

## 5. Физика blend из трёх сортов

1. **Разный** **размер** **зерна** → **fines** + **boulders** → **channeling** **на** **V60**.
2. **Timor/Ateng** **genes** → **быстрее** **горечь** **на** **96 °C**.
3. **Natural** **→** **sugars** **на** **surface** → **быстрее** **extract** **sweet** **и** **ferment** **together**.
4. **Иммерсия** **сглаживает** **разброс** **размерa**; **перcolation** **подчёркивает** **дефекты** **и** **кислоту**.
